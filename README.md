# SD Player

A clean, fast video player for Android, made by **ABDUL BASIR**.

## Features

- Finds every video on your phone, with previews, duration and quality tags
- Browse by **Videos**, **Folders** or **Recent**, with search and sorting
- Plays almost any format (MP4, MKV, WebM, AVI, MOV, HLS…) using Media3 / ExoPlayer
- **Resume** where you stopped, with a progress bar in the list
- Swipe the **left side** for brightness, the **right side** for volume, or swipe sideways to seek
- Double tap left or right to go back or forward 10 seconds
- Playback speed from 0.5x to 2x
- Multiple **audio tracks** and **subtitles**, plus loading your own .srt / .vtt / .ass file
- Screen fit modes: fit, crop to fill, stretch
- Lock the controls, rotate the screen, repeat one video
- **Picture in picture**
- Opens videos from file managers and other apps, and plays direct links (including .m3u8)
- Playlist of the folder or list you started from, with next and previous

## Get the app

1. On GitHub open **Actions → Build APK → Run workflow**.
2. When it finishes, open **Releases** and download `SDPlayer-<version>.apk`
   (use the `-debug.apk` if the first one does not work).
3. Install it on your phone.
